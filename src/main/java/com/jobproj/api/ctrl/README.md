# ctrl (Legacy)

> 초기 PoC 단계에서 사용하던 **레거시 컨트롤러 보관용** 패키지입니다.  
> 현재 표준 구조는 기능별 패키지(`resume/`, `section/`, `attachment/`, `jobs/` 등)이므로,
> 새로운 코드는 이 패키지에 추가하지 않습니다.

## 현황

- 주요 컨트롤러는 기능별 패키지로 이동하였으며,
  이 패키지는 과거 코드 참고용으로만 남겨둘 수 있습니다.

## 가이드

- 새 컨트롤러는 반드시 **기능별 패키지**에 생성합니다.
- 기존 `ctrl` 소스는 점진적으로 삭제하거나, 필요 시만 참고용으로 유지합니다.
