# common

> 공용 유틸리티/응답/페이지네이션 등 **도메인에 독립적인** 기능을 모아두는 패키지입니다.

## 주요 클래스

- `ApiResponse<T>`  
  - 모든 REST API에서 사용하는 표준 응답 래퍼 (성공/실패/메시지/데이터)
- `PageRequest`, `PageResponse`  
  - 페이징 요청/응답 DTO
- `JdbcUtils`  
  - JdbcTemplate 사용 시 공통 매핑/유틸 메서드
- `OwnerMismatchException`  
  - 리소스 소유자와 현재 로그인 사용자가 다를 때 사용하는 비즈니스 예외

## 규칙

- **비즈니스 로직, 보안, DB 접근** 자체는 이 패키지에 두지 않습니다.
- 다양한 도메인에서 재사용되는 **순수한 공통 타입/유틸리티**만 두고,
  의존 방향의 말단(끝)에서 사용되도록 유지합니다.
