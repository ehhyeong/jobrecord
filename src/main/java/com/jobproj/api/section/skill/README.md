# section/skill

> 이력서 내 **스킬(Skill)** 섹션 CRUD 를 담당하는 패키지입니다.

## 예시 필드

- 기술명(예: Java, Spring, React)
- 숙련도(예: 초급/중급/고급 또는 1~5 레벨)
- 사용 기간 또는 경험 연차
- 관련 경험(프로젝트/경력 참조) 등

## 구현 포인트

- owner 강제: 스킬 정보 역시 해당 이력서의 소유자 기준으로 관리합니다.
- 중복 스킬 처리 전략:
  - 동일 스킬 반복 입력 시 새 레코드 생성 vs 기존 레코드 업데이트 등 정책을 명확히 합니다.
